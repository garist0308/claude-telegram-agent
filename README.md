# claude-telegram-agent

MCP-сервер, который даёт Claude Code читать и отправлять сообщения и файлы в
Telegram **с личного аккаунта** — не с бота. Каждый, кто подключит сервер,
входит под своим собственным номером телефона; сервер не содержит ни одного
чужого ключа или токена.

```
Ты: «Отправь Маше, что встреча переносится на завтра»
        │
        ▼
Claude разбирает фразу → ищет получателя → решает, однозначен ли он
        │  MCP, транспорт stdio (локальный процесс, без сети)
        ▼
claude-telegram-agent — node-процесс на этой машине
        │  MTProto, сессия твоего личного аккаунта
        ▼
Telegram → сообщение уходит от твоего имени
```

Подробный разбор устройства, решений и их причин — в [`docs/DESIGN.md`](docs/DESIGN.md).

## Что внутри

| Файл | Зачем |
| --- | --- |
| `server.mjs` | MCP-сервер (stdio). Семь инструментов и все проверки безопасности |
| `tg.mjs` | Обёртка над GramJS: соединение MTProto, диалоги, отправка, чтение, скачивание, расшифровка голоса |
| `match.mjs` | Сопоставление «Маше» → «Маша Иванова». Чистые функции, без сети |
| `config.mjs` | Креды, флаги, лимиты частоты, журнал отправок |
| `login.mjs` | Одноразовый интерактивный вход в Telegram |
| `check.mjs` | Диагностика: что готово, что нет |
| `silence-stdout.mjs` | Держит stdout чистым — там только JSON-RPC |

## Установка

Нужны Node.js 18+ и [Claude Code](https://claude.com/claude-code).

```bash
git clone <URL этого репозитория>
cd claude-telegram-agent
npm install
npm run login     # одноразовый вход в свой Telegram, нужен телефон под рукой
npm run check      # диагностика: всё ли готово
```

Дальше подключи сервер к Claude Code (на уровне пользователя — тогда он
доступен из любой папки):

```bash
claude mcp add telegram -s user -- node "$(pwd)/server.mjs"
```

После этого можно просто попросить Claude: «Отправь Маше, что встреча
переносится на завтра» — он сам найдёт получателя и отправит.

## Инструменты MCP

| Инструмент | Что делает |
| --- | --- |
| `telegram_whoami` | Чей аккаунт подключён. Проверка связи |
| `telegram_list_dialogs` | Список диалогов: id, title, username, type. Без текстов сообщений |
| `telegram_find_recipient` | «Маше» → кандидаты с уровнем совпадения. Сам не выбирает |
| `telegram_send_message` | Отправка текста. Требует `peer` + `expect_title`, сверяет их между собой; `reply_to_message_id` — чтобы ответить на конкретное сообщение |
| `telegram_read_messages` | Сообщения диалога; `offset_id` — постраничный проход по всей истории; голосовые и видео-кружки расшифровываются в текст (Premium) |
| `telegram_send_file` | Отправка файла с этого компьютера по абсолютному пути. Те же проверки, что у отправки сообщения |
| `telegram_download_file` | Скачивание файла из конкретного сообщения (`message_id` из `telegram_read_messages`) в папку на диске |

## Что сервер запрещает

Агент здесь — сам Claude, поэтому ограничения не могут жить в промпте: промпт
агент может переосмыслить. Все запреты проверяет сервер:

- **Сверка получателя.** Чтобы отправить или прочитать, агент обязан назвать
  не только `peer`, но и `expect_title` — имя, которое он ожидает у этого
  диалога. Сервер спрашивает Telegram, кто это на самом деле, и отказывается
  при расхождении.
- **Только личные диалоги с людьми.** Группы и каналы запрещены; боты тоже.
- **Лимиты частоты.** Не чаще 1 отправки (текст или файл) в 5 секунд, не
  больше 20 в час. За флуд через MTProto Telegram банит аккаунт навсегда.
- **Размер файла.** Не больше 50 МБ (`TELEGRAM_MCP_MAX_FILE_MB`) что при
  отправке, что при скачивании. `telegram_send_file` принимает только
  абсолютный путь к уже существующему файлу; `telegram_download_file` —
  только абсолютный путь к папке назначения.
- **Журнал.** Каждая отправка пишется в `~/.telegram-mcp/sent.log`.

Полный список переменных окружения, частых ошибок и ограничений — в
[`docs/DESIGN.md`](docs/DESIGN.md).

## Доступ и его отзыв

Креды лежат в `~/.telegram-mcp/credentials.json` с правами `0600`, вне
репозитория. Строка сессии равносильна паролю от Telegram.

```bash
claude mcp remove telegram -s user   # отключить от Claude
rm -rf ~/.telegram-mcp               # удалить креды с машины
```

Отозвать саму сессию: Telegram → **Settings** → **Devices** → удалить сессию.
Это надёжнее удаления файла: после отзыва строка сессии мертва где угодно.
